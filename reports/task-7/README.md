# 任务 003 交付：「Hamlet的小站」界面优化方案

> 交付人：friend-agent（Claude）· 状态：**未部署**，仅供人类参考
> 范围：本交付只包含界面优化方案与独立静态 mock。任务中的安全检查部分未执行，原因是本 agent 所用模型的使用策略不允许它对无法核实授权的第三方站点做检查。建议站长本人用常见的公开体检工具自查。

- 静态 mock：[`mock/index.html`](mock/index.html)，独立文件，所用数据全部虚构，不连接任何生产接口
- 示意截图：[`screenshots/`](screenshots/)，含桌面、手机，浅色、深色

## 设计前提：保留什么

当前站点的气质很鲜明，所有建议都在下面这些约束之内：

| 保留 | 说明 |
|---|---|
| 纸色 / 墨色 | `--paper #e8e8dd`、`--ink #000`，深色时反转，只换色不改布局 |
| 衬线大标题 | Noto Serif SC 900，报刊式的报头 |
| 等宽点缀 | IBM Plex Mono 用于 kicker、状态条、编号、标签 |
| olive / accent | olive 用于次要信息，橙色 accent 用于强调和悬停 |
| 硬阴影卡片 | `3px 3px 0` 的墨色硬阴影、细边框、小圆角 |

不做的事：不改成像素终端风、不换成通用后台模板、不加渐变或毛玻璃、不引入 UI 框架。

## 优化建议（按收益排序）

### 1. 把「深色阅读」和「管理模式」拆开 ★ 收益最高
- **现状**：深色外观只在进入隐藏的管理模式时才出现。普通访客晚上看页面，没有深色可用；而站长想用深色阅读时，又会顺带出现一堆编辑控件。
- **改法**：
  - 深色主题作为普通功能：页面右上角加一个「浅 / 深」切换，默认跟随系统的 `prefers-color-scheme`，选择记在 `localStorage`。
  - 管理模式单独保留：在报头 kicker 右侧显示一个明确的「编辑中」状态牌，与深浅色互不影响。
- **保持的气质**：深色仍然只换色、不改布局，切换按钮用等宽小字加细边框胶囊，和现有的 `.edit-btn` 同一套样式。

### 2. 在线状态不只靠颜色
- **现状**：卡片右上角只用红、绿两色的小圆点表示在线或离线，色弱用户分辨不出，截图打印成黑白后也看不出来。
- **改法**：圆点旁加一个等宽小字标签 `ONLINE` / `OFFLINE`；离线卡片的标题加删除线式的淡化，而不是整卡降透明度。
- **保持的气质**：标签沿用 kicker 的字距和字号，读起来像报纸栏目标注。

### 3. 找东西：筛选与搜索
- **现状**：站点一多，只能从头滚到尾。
- **改法**：在状态条下方加一行轻量工具条：
  - 左侧是分段筛选「全部 / 在线 / 离线」，并显示每档的数量；
  - 右侧是一个搜索框，按 `/` 聚焦，匹配标题、描述和域名；
  - 没有结果时显示「没有匹配的站点」。
- **保持的气质**：工具条用 1px 墨线上下分隔，和现有 `.sysbar` 形成同一套「报纸分栏」节奏，不加阴影、不加底色。

### 4. 卡片信息层级
- **现状**：描述被强制压成一行，末尾省略号吃掉了关键信息；10px 的标签在手机上太小。
- **改法**：
  - 描述最多显示两行（`line-clamp: 2`）；
  - 标签字号改成 11px，域名标签和内网标签分成两行显示；
  - 编号 `NO.01` 与状态标签放在同一行，左右对齐。
- **保持的气质**：衬线标题、等宽描述、橙色胶囊标签都不变，只调字号和行数。

### 5. 系统状态条在手机上的排布
- **现状**：窄屏时每格宽 45%，5 个格子会排成 2 + 2 + 1，最后一格孤零零占一行，边框也对不齐。
- **改法**：窄屏时改用 CSS Grid 两列排布；奇数个格子时，让最后一格横跨两列；数值和进度条对齐到同一基线。
- **保持的气质**：仍然是上 3px、下 1px 的墨线框，只改内部网格。

### 6. 首屏节奏（手机）
- **现状**：手机上 `h1` 的字号下限是 44px，报头加状态条差不多占满第一屏，看不到任何卡片。
- **改法**：
  - 窄屏时标题下限降到 36px，报头上边距从 52px 降到 28px；
  - 状态条在窄屏只显示短数值（`MEM 62%`、`LOAD 0.42`），完整数值（`4.9G/7.8G`、三段负载）留给桌面，避免数值折成两行。
- **保持的气质**：大衬线标题依然是视觉中心，只是让第一屏能露出卡片。

### 7. 键盘和可访问性
- **现状**：卡片只有鼠标悬停效果，用键盘 Tab 过去看不出焦点落在哪里。
- **改法**：
  - 加上 `:focus-visible` 样式：2px 的 accent 描边，加上和悬停相同的位移硬阴影；
  - 在 `prefers-reduced-motion` 下取消卡片位移和颜色过渡；
  - 卡片设置 `aria-label="站点名 · 在线"`。
- **保持的气质**：焦点态直接复用悬停态的「翘起」效果，交互语言保持一致。

### 8. 加载与空状态
- **现状**：页面加载时只显示「加载中…」一行字，数据到了之后布局会跳一下。
- **改法**：用 3～6 张骨架卡占位，骨架卡用纸色加细边框，不做闪烁动画；「配置同步于」改成相对时间（如「3 分钟前」），悬停时再显示具体时间。
- **保持的气质**：骨架卡就是去掉内容的卡片轮廓，不引入灰色色块的通用骨架风格。

### 9. 字体加载
- **现状**：三套字体都从第三方镜像加载，首屏要等字体下载完成，中文衬线字体的体积尤其大。
- **改法**：
  - 把标题实际用到的字做子集化后自托管，`font-display: swap`；
  - 正文依靠系统字体回退（宋体、苹方、雅黑）；
  - `IBM Plex Mono` 同样自托管，体积很小。
- **保持的气质**：字体家族不变，只改变字体从哪里、怎么加载。

## mock 说明

`mock/index.html` 是一个单文件，可以直接用浏览器打开，演示了上面第 1～8 条：

- 右上角有「浅 / 深」切换，默认跟随系统设置，只换色、不改布局；
- 「全部 / 在线 / 离线」筛选和搜索框都能用，按 `/` 可以聚焦搜索框；
- 在线状态同时用颜色和文字标签表示；
- 手机宽度下状态条收成两列，首屏能看到卡片；
- 键盘焦点态、`prefers-reduced-motion`；
- 管理模式没有做进 mock，因为它属于站长的私有功能，只在第 1 条里给出设计建议。

mock 没有引用任何外部字体或资源，在离线状态下也能完整显示。字体使用系统回退，用来示意自托管以前的最差情况。

## 已知限制

- 方案只基于公开首页的结构和样式，没有看过管理模式里的实际使用流程。
- mock 用的是虚构数据，真实站点数量、名称长度不同，效果会有差异。
- 未部署，也没有改动任何生产文件。
